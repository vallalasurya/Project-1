# Hello World HTML Project

## 📌 Project Overview

This is a simple HTML project created to learn the basics of web development. The webpage displays a "Hello World" message (or a custom name/message) using HTML.

## 🎯 Objective

* Learn the basic structure of an HTML document.
* Understand how HTML elements work.
* Practice creating and viewing a webpage in a web browser.

## 🛠️ Technologies Used

* HTML5
* Visual Studio Code
* Web Browser (Google Chrome, Microsoft Edge, etc.)

## 📂 Project Structure

```
hello-world/
│── index.html
└── README.md
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click the file and select **Open with Live Server** (if installed), or open it directly in your web browser.

## 📸 Output

The webpage displays a simple greeting such as:

```
Hello World!
```

or

```
Hello, [Your Name]!
```

## 📚 Learning Outcomes

* Created a basic HTML webpage.
* Learned the structure of an HTML document.
* Understood how to use headings and text elements.
* Gained experience using Visual Studio Code and GitHub.
